## Domain Concepts

### `NoteNameEnum`
Represents the twelve distinct pitch classes in Western music.

**📦 Content**:
- `C`
- `C#`
- `D`
- `D#`
- `E`
- `F`
- `F#`
- `G`
- `G#`
- `A`
- `A#`
- `B`

### `OctaveRangeConstant`
Defines the specific range of octaves covered by the musical keyboard.

**📦 Content**:
- `START_OCTAVE`: 3
- `END_OCTAVE`: 5

### `NoteIdentifier`
A string type that uniquely identifies a specific musical note by combining its `NoteNameEnum` and its octave number (e.g., "C3", "F#4", "B5").

### `KeyboardKeyMapConstant`
Defines the ordered list of physical keyboard key codes that correspond to the notes on the virtual keyboard. The order of these keys directly maps to the order of notes generated by `getAllNotesInKeyboardRange`.

**📦 Content**:
- `KEY_CODES`: Array<string>
  - `KeyQ` (Maps to C3)
  - `Digit2` (Maps to C#3)
  - `KeyW` (Maps to D3)
  - `Digit3` (Maps to D#3)
  - `KeyE` (Maps to E3)
  - `KeyR` (Maps to F3)
  - `Digit5` (Maps to F#3)
  - `KeyT` (Maps to G3)
  - `Digit6` (Maps to G#3)
  - `KeyY` (Maps to A3)
  - `Digit7` (Maps to A#3)
  - `KeyU` (Maps to B3)
  - `KeyI` (Maps to C4)
  - `Digit9` (Maps to C#4)
  - `KeyO` (Maps to D4)
  - `Digit0` (Maps to D#4)
  - `KeyP` (Maps to E4)
  - `BracketLeft` (Maps to F4)
  - `Equal` (Maps to F#4)
  - `BracketRight` (Maps to G4)
  - `Backslash` (Maps to G#4)
  - `KeyA` (Maps to A4)
  - `KeyS` (Maps to A#4)
  - `KeyD` (Maps to B4)
  - `KeyF` (Maps to C5)

## Component: KeyboardDomain
### Role: Domain

### ⚡ Capabilities

#### `getNoteIdentifier`
Creates a unique string identifier for a specific musical note.

- **Contract**: Generates a canonical string representation for a given note name and octave.
- **Signature**: `(noteName: NoteNameEnum, octave: number) -> NoteIdentifier`
- **Flow**:
  1.  Concatenate the `noteName` string with the `octave` number.
  2.  Return the resulting `NoteIdentifier` string.
- **🚨 Constraint**:
  - The `octave` input MUST be an integer within the range defined by `OctaveRangeConstant`.
  - The `noteName` input MUST be one of the values from `NoteNameEnum`.
- **✅ Acceptance Criteria**:
  - Given `NoteNameEnum.C` and `octave: 4`, the output MUST be "C4".
  - Given `NoteNameEnum.F#` and `octave: 3`, the output MUST be "F#3".
- **🧪 Test Scenarios**:
  - Test with `C`, `3` -> "C3"
  - Test with `G#`, `4` -> "G#4"
  - Test with `B`, `5` -> "B5"

#### `getAllNotesInKeyboardRange`
Generates an ordered list of all `NoteIdentifier`s that comprise the 3-octave keyboard, starting from the lowest note of the lowest octave to the highest note of the highest octave.

- **Contract**: Provides a complete, ordered inventory of all playable notes on the keyboard.
- **Signature**: `() -> Array<NoteIdentifier>`
- **Flow**:
  1.  Initialize an empty list `allNotes`.
  2.  FOR EACH `octave` from `OctaveRangeConstant.START_OCTAVE` to `OctaveRangeConstant.END_OCTAVE`:
      1.  FOR EACH `noteName` in `NoteNameEnum` in its defined order (C, C#, D, ... B):
          1.  Generate `noteIdentifier` using `getNoteIdentifier(noteName, octave)`.
          2.  Add `noteIdentifier` to `allNotes`.
  3.  Return `allNotes`.
- **🚨 Constraint**:
  - The order of notes within an octave MUST follow the standard chromatic scale (C, C#, D, D#, E, F, F#, G, G#, A, A#, B).
  - The order of octaves MUST be ascending (e.g., Octave 3 notes, then Octave 4 notes, then Octave 5 notes).
- **✅ Acceptance Criteria**:
  - The returned array MUST contain exactly 36 `NoteIdentifier`s (12 notes/octave * 3 octaves).
  - The first element of the array MUST be "C3".
  - The last element of the array MUST be "B5".
  - The array MUST be ordered chromatically and by ascending octave.
- **🧪 Test Scenarios**:
  - Verify `getAllNotesInKeyboardRange().length` is 36.
  - Verify `getAllNotesInKeyboardRange()[0]` is "C3".
  - Verify `getAllNotesInKeyboardRange()[11]` is "B3".
  - Verify `getAllNotesInKeyboardRange()[12]` is "C4".
  - Verify `getAllNotesInKeyboardRange()[35]` is "B5".
  - Verify that "E4" is present in the list.

#### `getKeyToNoteMapping`
Provides a one-to-one mapping from predefined physical keyboard key codes to their corresponding `NoteIdentifier`s, covering all notes in the keyboard range.

- **Contract**: Generates a canonical mapping for global keyboard event handling, associating specific physical keys with musical notes.
- **Signature**: `() -> Array<{ keyCode: string, noteIdentifier: NoteIdentifier }>`
- **Flow**:
  1.  Retrieve the ordered list of all notes using `getAllNotesInKeyboardRange()`. Let this be `allNotes`.
  2.  Retrieve the ordered list of predefined key codes from `KeyboardKeyMapConstant.KEY_CODES`. Let this be `keyCodes`.
  3.  Initialize an empty list `keyNoteMapping`.
  4.  FOR `index` from 0 to `allNotes.length - 1`:
      1.  Create a mapping entry: `{ keyCode: keyCodes[index], noteIdentifier: allNotes[index] }`.
      2.  Add this entry to `keyNoteMapping`.
  5.  Return `keyNoteMapping`.
- **🚨 Constraint**:
  - The number of `KEY_CODES` in `KeyboardKeyMapConstant` MUST exactly match the number of notes returned by `getAllNotesInKeyboardRange`.
  - Each `keyCode` in the mapping MUST be unique.
  - Each `noteIdentifier` in the mapping MUST be unique.
- **✅ Acceptance Criteria**:
  - The returned mapping MUST contain exactly 36 entries.
  - The entry for `KeyQ` MUST map to "C3".
  - The entry for `KeyV` MUST map to "B5".
  - The mapping for `KeyE` MUST be "E3".
  - The mapping for `KeyP` MUST be "E4".
- **🧪 Test Scenarios**:
  - Verify `getKeyToNoteMapping().length` is 36.
  - Verify `getKeyToNoteMapping()[0].keyCode` is "KeyQ" and `getKeyToNoteMapping()[0].noteIdentifier` is "C3".
  - Verify `getKeyToNoteMapping()[4].keyCode` is "KeyE" and `getKeyToNoteMapping()[4].noteIdentifier` is "E3".
  - Verify `getKeyToNoteMapping()[35].keyCode` is "KeyV" and `getKeyToNoteMapping()[35].noteIdentifier` is "B5".
  - Verify that all `keyCode` values in the mapping are unique.
  - Verify that all `noteIdentifier` values in the mapping are unique.
