**ARCHITECT'S PLAN (Global Context)**:
- **keyboard-domain.isl.md** [Domain]
  Description: Defines musical notes, octaves, and the structure of a 3-octave keyboard. Key Concepts: `NoteNameEnum` (e.g., C, C#, D), `OctaveRangeConstant` (e.g., 3-5 for 3 octaves), `getNoteIdentifier(noteName, octave)` function, `getAllNotesInKeyboardRange()` function to list all playable notes.
  Dependencies: None

- **tone-synth-logic.isl.md** [Business Logic]
  Description: Manages the Tone.js synthesizer, including initialization, playing, and stopping notes. Key Capabilities: `initSynth()` (initializes Tone.js context and synth), `playNote(noteIdentifier, duration)` (triggers a note sound), `stopNote(noteIdentifier)` (stops a playing note), `setVolume(level)` (adjusts master volume). Uses Tone.js for sound generation.
  Dependencies: keyboard-domain.isl.md

- **keyboard-ui.isl.md** [Presentation]
  Description: Renders the visual keyboard interface (keys for 3 octaves) and handles user interactions (mouse clicks on keys, keyboard presses). Key Capabilities: `renderKeyboard(noteIdentifiers)` (draws the keys), `onNotePressed(callback)` (registers a callback for when a key is pressed), `onNoteReleased(callback)` (registers a callback for when a key is released), `highlightKey(noteIdentifier)` (visually highlights a key), `unhighlightKey(noteIdentifier)` (removes highlight).
  Dependencies: keyboard-domain.isl.md

- **main.isl.md** [Presentation]
  Description: The application entry point. Imports Tone.js from CDN, initializes the synthesizer logic, renders the keyboard UI, and connects UI events to sound logic. Responsibilities: `Import Tone.js from CDN (cdnjs)`, `Initialize ToneSynthLogic`, `Render KeyboardUI using notes from KeyboardDomain`, `Wire up KeyboardUI.onNotePressed to ToneSynthLogic.playNote`, `Wire up KeyboardUI.onNoteReleased to ToneSynthLogic.stopNote`, `Handle global keyboard events (e.g., 'keydown', 'keyup') to trigger note playback and UI highlighting.`
  Dependencies: tone-synth-logic.isl.md, keyboard-ui.isl.md
